# Word Scramble Game

A simple command-line Word Scramble game built with Python.

The program randomly selects a word, scrambles its letters, and challenges the player to guess the original word.

## Features

* Random word selection
* Random letter shuffling
* User guess validation
* Play multiple rounds

## Concepts Practised

* Lists
* Strings
* Loops
* Conditional statements
* Python's `random` module
* `list()`, `random.shuffle()`, and `join()`

Part of my **30 Days of Python** challenge, documenting one project and one new learning experience each day.
